# ham-tcos-app

Ham Study: a free study guide for the US amateur radio exams, built from the
public-domain question pools published by the NCVEC. Live at
<https://ham.tcos.app>.

This is a child of [tcos-app](https://github.com/Twin-Cities-Open-Systems/tcos-app),
which hosts `tcos.app` and keeps the registry of apps on that domain.

The site has two pages: a landing page and the study page (guide, browse by
question, flashcards, practice exam, mastery and progress, all kept in the
browser's local storage; nothing is sent anywhere).

## Layout

| Path | What it is |
| --- | --- |
| `index.html`, `study.html` | the two pages |
| `css/`, `js/` | styles and scripts, no third-party code, no external requests |
| `data/ham-study.json`, `data/ham-figures/` | generated by `build.py`; committed, and what ships |
| `build.py` | builds `data/` from `ham/`; `--check` fails if the committed data is stale |
| `ham/pools/` | the three NCVEC question pools and the 14 figures they reference |
| `ham/families.yaml` | groups the subelements into study families (colors) |
| `tests/` | the generator's tests |
| `robots.txt`, `sitemap.xml` | crawler policy and page list |
| `deploy.sh` | `lab` and `promote` steps, driven by `hee release` |
| `release.card.v1.yaml` | the release card `hee release` reads |
| `.github/workflows/ci.yml` | `hee-check`, data drift and tests, then publishes the lab payload from `main` |

## Question pools

`ham/pools/` is copied unchanged from the org's resume repo at commit `d8410a6`
(2026-09-12): Technician 2026-2030, General 2023-2027 and Extra 2024-2028,
1431 questions in all, as published by the NCVEC. Each pool card carries its
validity dates. When the NCVEC publishes a new pool, add it under `ham/pools/`,
add its subelements to `ham/families.yaml`, then rebuild.

## Rebuilding the data

    python3 build.py            # needs PyYAML; writes data/
    python3 build.py --check    # writes nothing; exit 2 if data/ is stale
    python3 -m unittest discover -s tests

Commit the regenerated `data/`: promote ships committed files with no rebuild.

## Releasing

Releases go through `hee release`, never by hand:

    hee release -lab              # confirm the lab serves main
    hee release -cut -yes         # release PR (the merge is the sign-off)
    hee release -promote -yes     # deploy to ham.tcos.app, signed prod tag
